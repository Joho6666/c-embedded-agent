# C-Embedded Agent

专注 C 语言与嵌入式开发的 AI 工程师。桌面端前端 Prototype（Next.js），默认深色 IDE 布局，数据全部 Mock。

## 启动

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 演示

Dashboard 或 Agent 页点击 **STM32 LED Demo** / **Run Agent**，会播放完整时间轴：需求分析 → 读手册 → 生成代码 → 编译失败 → 自动修复 → Build Successful → Flash → Serial → Validation Passed。

快捷键：`Ctrl+K` 命令面板 · `Ctrl+B` Build · `Ctrl+Shift+F` Flash · `` Ctrl+` `` Terminal。
