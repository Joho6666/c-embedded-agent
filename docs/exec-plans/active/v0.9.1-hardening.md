## 8. Planned Changes (v0.9.1 Sprint)

1. **8051 Real CI**:
   - Add `scripts/8051_golden_build.py` (strict returncode, non-empty .ihx and .hex, memory limit check).
   - Add `8051-golden` job to `.github/workflows/ci.yml`.
   - Update `8051-sdcc` status to `Experimental / Compile Verified`.
2. **Phase-Aware Crash Resume**:
   - Add `idempotent`, `resume_policy`, `replay_safe`, and `irreversible` fields to `ToolSpec`.
   - Extend `RunCheckpoint` with `phase`, `step_id`, `completed_steps`, `pending_step`, `idempotency_key`, `last_tool_call`, `last_tool_result`, `workspace_snapshot`.
   - Rewrite `resume_run()` to resume at the pending phase/step without repeating writes or replaying dangerous tools.
   - Add integration tests in `backend/tests/test_run_resume_integration.py` covering crash injections across all phases.
3. **Structured Planner & Capability Checking**:
   - Standardize `ActionPlan` JSON schema with `resumePolicy`, `expectedEvidence`, and preconditions.
   - Ensure planner checks environment/probe status and never outputs false promises like `Expected: PASS` when hardware is missing.
4. **Benchmark Hardening**:
   - Support `--smoke`, `--resume`, failure taxonomy breakdown, and diff evidence generation.
5. **Human-in-the-Loop Hardware & Evidence Hierarchy**:
   - Add `WAITING_FOR_USER` state for manual interactions (cold reboot, button push).
   - Standardize `evidence/` directory hierarchy (`ci/`, `local/`, `benchmark/`, `hardware/`).
6. **Error Memory & Context Router Budgets**:
   - Verify count increments only on full pass (`patch + compile + validate`).
   - Track `success_count`, `failure_count`, and `confidence`.
   - Add token/char budgets to Context Router with telemetry.
7. **Version Bump & Consistency Gate**:
   - Bump `VERSION`, `package.json`, and backend release report to `0.9.1-beta`.
   - Add `backend/tests/test_version_consistency.py`.
