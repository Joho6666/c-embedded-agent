# Routing

The classifier returns task type, platform, modules, context level, confidence and concise reasons. Workflows are Feature, Bugfix, Platform, Hardware Debug, Architecture and Release; module steps accumulate for multi-peripheral requests.

Context priority is platform facts, current errors, explicitly named files/symbols, relevant sources, selected skills/knowledge, then project tree. Routed context is replaced per turn and records truncation. Disabled or platform-mismatched skills are excluded; composite skills rank ahead of generic matches.
